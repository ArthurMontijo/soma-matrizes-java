# Soma de Matrizes em Java

## Descrição

Programa desenvolvido em Java que realiza a soma de duas matrizes 2x2 utilizando JOptionPane.

O programa:
- Lê os valores da matriz A
- Lê os valores da matriz B
- Faz a soma das matrizes
- Exibe a matriz resultado na tela

## Como executar

1. Abra o projeto na IDE
2. Compile o programa
3. Execute a classe ProgramaMatriz

## Exemplo de uso

Entrada:

Matriz A:
1 2
3 4

Matriz B:
5 6
7 8

Saída:

Resultado da soma:

6 8
10 12

## Tecnologias utilizadas

- Java 21
- JOptionPane
